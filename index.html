What is this?

AUI Secure pairs a fully-functional Flask security lab (SQL injection, XSS, password hashing, CSRF, rate limiting, and more — attack vs. defence, side by side) with an automated DevSecOps pipeline that guards the codebase itself. Every push runs through secret scanning, static analysis, dependency auditing with automatic remediation, and a dynamic scan against the live app. Pre-commit hooks mirror the same checks locally, so vulnerabilities are caught before they ever reach GitHub.

// pipeline

5-stage security gauntlet

Stage 1  Build & Tests     pytest — functional + security test suite
Stage 2  Secret Scanning   gitleaks — blocks hardcoded secrets
Stage 3  SAST              bandit — static code security analysis
Stage 4  SCA + Auto-fix    pip-audit → remediate.py → opens PR
Stage 5  DAST (push only)   OWASP ZAP baseline scan vs. live app
  • Auto-remediation — when pip-audit finds a vulnerable dependency, remediate.py patches requirements.txt and opens a pull request automatically.
  • Pre-commit parity — black, bandit, pip-audit, gitleaks, and file-hygiene checks run locally before a commit ever reaches GitHub.
  • Dual-endpoint labs — every vulnerability class (SQLi, XSS, CSRF, lockout, headers) ships a vulnerable and a hardened endpoint for live comparison.
  • SECURE_MODE gating — insecure demo endpoints stay server-side gated, so the same codebase is both a teaching tool and production-safe.
  • Full audit trail — every login, query, and API call is logged and streamed to a live events feed.
